# Nagłówki HTTP

## Nagłówki zapytania (request)
1. **User-Agent** – informuje serwer o przeglądarce/kliencie wysyłającym żądanie.
2. **Accept** – określa, jakie typy odpowiedzi klient może obsłużyć (np. `application/json`).
3. **Host** – wskazuje, do jakiej domeny kierowane jest żądanie.

## Nagłówki odpowiedzi (response)
1. **Content-Type** – określa format danych w odpowiedzi (np. `application/json`).
2. **Server** – podaje informacje o serwerze obsługującym żądanie.
3. **Date** – data i czas wygenerowania odpowiedzi przez serwer.
